# 🐍 Snake Game на C++

Консольная игра "Змейка" для изучения основ C++ и Git.

## 🎯 Цели проекта
- Освоить синтаксис C++
- Научиться работать с Git и GitHub
- Создать законченный проект для портфолио

## 📊 Прогресс
- [x] Настройка окружения
- [x] Статичная рамка поля
- [x] Движущаяся точка
- [x] Логика змейки
- [x] Система очков
- [x] Меню игры

## 🛠️ Сборка
### Вариант №1 (Makefile)
```bash
make run
```

### Вариант №2 (Cmake)
```bash
# Создание директории для сборки
mkdir build
cd build

# Конфигурация проекта
cmake ..

# Компиляция
cmake --build .
```
